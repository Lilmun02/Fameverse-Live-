# Fameverse 0.2.0 — Build 16 Candidate

This checkpoint freezes the current native Build 16 candidate for CI and physical QA.

Included scope:
- Fameverse iOS and Android native branding with the canonical crown icon and Fameverse display name.
- V2 native live experience and existing Stream media-provider lock.
- Native profile revamp and Creator Studio entry.
- Creator payout foundation with a $25 minimum, verification gate, cleared-earnings requirement, moderation review, and PayPal provider integration.
- Owner-only PayPal Sandbox payout QA flow. Synthetic QA earnings do not define production gift-to-cash economics.
- Owner-only external Fame Coin recharge QA foundation. Public recharge economics remain intentionally unlocked.

Release law:
- CI green does not equal physical acceptance.
- Device verification is required before Build 16 is called Release Passed.
- The physical acceptance lock must not be bypassed.
- No media-provider swap, creator percentage, or public coin-to-cash conversion is authorized by this checkpoint.
