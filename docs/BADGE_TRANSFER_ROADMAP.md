# Fameverse Badge Transfer — Future Feature

Status: future/read-only concept. Do not activate transfer awards in the current beta until the review and conversion system is implemented.

## Supported source apps
- TikTok
- Favorited
- EPIC

Echo is intentionally excluded.

## Transfer rules
- A Fameverse user may transfer from only one supported source app.
- Proof is a screen recording of the user's source-app account and badge.
- The account/username shown in the recording and the badge shown in the recording must match the submitted transfer claim.
- Fameverse manually reviews the recording.
- Matching submission: approve.
- Mismatch or insufficient proof: deny.
- A denied user may submit a new recording and try again.
- Imported badges cannot be stacked across multiple source apps.

## Conversion
The source badge/level must be converted to the appropriate Fameverse badge/level using a maintained conversion table. Do not guess or hard-code equivalence until the source-app badge economies/levels have been reviewed.

## Current beta
This document preserves the feature for a later update. It must not interfere with the current release-candidate basics, Live stability, authentication, profiles, discovery, or payments.
