# Famaverse Live V2 approved UI lock

Physical design approval: 2026-09-19.

Locked host Live layout:
- Full-screen camera stage, no boxed video.
- Top-left: avatar, creator name, verification badge, LIVE badge, live title beneath.
- Solid/semi-opaque dark identity background; no backdrop blur, frost, haze, or cloudy UI.
- Top-right stats order: `F <FameTap count> | viewers <viewer count>`, then End.
- Bottom order: comment composer, purple Rose quick gift, gift tray, share/send, large F menu.
- F menu owns host controls such as camera flip, microphone, camera on/off, and co-host access.
- No separate FameTaps bottom button, no lightning-bolt control, no duplicate viewer count, no live timestamp yet.
- One shared visual shell for iPhone and Android. Device-specific presentation forks are forbidden.
- Do not move or rename locked UI elements without CEO approval.
